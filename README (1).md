# 🌙 Lunaria — Карта Дня

Таро Mini App для Telegram: ежедневный ритуал вытягивания карты с толкованием,
дневником, коллекцией арканов, достижениями и петлёй возврата.

Двуязычный интерфейс — українська / русский.

## ✨ Возможности

- **Карта дня** — одно вытягивание в сутки с анимированным ритуалом перетасовки колоды
- **Перевёрнутые карты** — 50% шанс выпадения карты в перевёрнутом положении с теневым толкованием
- **Развёрнутое толкование** — суть карты, что стоит сделать, чего избегать, аффирмация
- **Вечернее эхо** — петля возврата: вечером пользователь отмечает, как карта откликнулась
- **Стрик** — счётчик дней подряд с «заморозкой» (один пропуск не обнуляет серию)
- **Коллекция** — 22 старших аркана, открываются по мере выпадения
- **Дневник** — история карт с недельной сводкой
- **Достижения** — 6 бейджей за разные действия
- **Премиум-звук** — мягкая мистическая атмосфера на Web Audio API (без аудиофайлов)
- **Шеринг** — генерация карточки дня в PNG для сторис

## 🚀 Запуск

### Локально

Открыть `index.html` в браузере. Telegram-функции (CloudStorage, тактильная
отдача, автоподстановка имени) при этом молча отключены — приложение
использует `localStorage` как запасное хранилище.

### Как Telegram Mini App

1. Залить содержимое репозитория на любой хостинг с HTTPS:
   - **GitHub Pages** — включить в Settings → Pages, ветка `main`, папка `/root`
   - либо Vercel / Netlify / Cloudflare Pages — подключить репозиторий
2. Открыть [@BotFather](https://t.me/BotFather) в Telegram
3. Создать бота: `/newbot`
4. Создать Mini App: `/newapp` → выбрать бота → указать URL опубликованной страницы
5. Открыть Mini App по ссылке вида `t.me/ваш_бот/имя_приложения`

После публикации по HTTPS заработают все Telegram-функции: облачное
сохранение прогресса между устройствами, haptic-отклик, имя из профиля.

## 🛠 Технологии

- Чистый HTML / CSS / JavaScript — без зависимостей и сборки
- [Telegram WebApp SDK](https://core.telegram.org/bots/webapps) — `telegram-web-app.js`
- Web Audio API — синтез эмбиента, колокольчиков и реверберации
- Canvas API — генерация карточки для шеринга
- Хранилище: Telegram CloudStorage с фолбэком на localStorage

## 📁 Где что в коде

Внутри `index.html`:

- `DECK` — массив из 22 карт, у каждой поля `uk` / `ru` с прямым и
  перевёрнутым толкованием (`e/d/a/af` и `re/rd/ra/raf`)
- `I18N` — все тексты интерфейса на двух языках
- `ACHS` — список достижений
- `S` — объект состояния, сохраняется под ключом `lunaria_v1`
- `drawCard()` — ритуал вытягивания и анимация перетасовки
- блок `PREMIUM AMBIENT SOUND ENGINE` — весь звук
